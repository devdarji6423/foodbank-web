# 🍲 FoodBank Web

A responsive React web application built for a local food bank, designed to connect the community with the resources it needs. The platform allows visitors to learn about the food bank's services, view its impact through key statistics, and get involved through donating, volunteering, or fundraising — all through clean, interactive modals.

## ✨ Features

- **Hero Section** – A welcoming landing area with quick-access buttons to donate or request help.
- **Our Services** – Highlights food distribution, emergency assistance, and community kitchen programs.
- **Our Impact** – Displays key statistics such as meals served, families helped, and active volunteers.
- **Get Involved** – Interactive options for donating food, volunteering, or organizing a fundraiser.
- **Modals** – Dedicated pop-up forms for Donate, Get Help, and Volunteer actions.

## 🛠️ Built With

- [React](https://reactjs.org/) – Front-end library for building the UI
- [Create React App](https://create-react-app.dev/) – Project bootstrapping and build tooling

## 📌 About the Project

This was developed as my second-year university project, with the goal of practicing component-based architecture, state management with React hooks, and building a real-world, socially impactful application.
